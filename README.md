# O-System V1 — Clean Production

O is a lightweight dispatch platform with three partner services: O-Ride, O-Drive and O-Movers.

## Production deployment
- Python: 3.13
- Start: `gunicorn --workers 1 --threads 8 --timeout 120 app:app`
- Persistent data: `/var/data/o_system_v1.db`
- Required Render secrets: `USER_NAME`, `PASSWORD`, `SECRET_KEY` (SECRET_KEY can be generated by Render)

## Partner access
Partners can sign in from the service entry pages using their username, full name, or phone number plus their password. The service selected at login must match the service assigned by admin.

## Compatibility routes
- `/manifest.json` -> service manifest
- `/favicon.ico` -> O logo
- `/o` and `/o/` -> O Services
- `/pulse_receiver` -> quiet 204 heartbeat compatibility endpoint

## UI
Customer pages use a warm sky-blue / cream visual system. O-Ride, O-Drive and O-Movers use service-specific friendly accents. Operational instruction-heavy notes were removed from the booking flow.
