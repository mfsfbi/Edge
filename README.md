# O Mobility PWA

Standalone Flask PWA for O-Bikes, O-Ride and O-Movers, with O-Travel linking to OTravel.

## Deploy on Render

Recommended: attach a persistent disk mounted at `/var/data` to the web service. Set `DATA_DIR=/var/data`. This is important for SQLite persistence, backups and uploaded assets.

Environment variables:
- `SECRET_KEY` — generated by Render or set yourself.
- `ADMIN_PASSWORD` — optional initial admin password (default is `ChangeMeNow!` on first boot; change it immediately).
- `DATA_DIR` — persistent data directory, default `/var/data` when set, otherwise `instance`.
- `OTRAVEL_URL` — optional OTravel URL.

Admin: `/admin/login`

The system uses soft deactivation instead of destructive deletion for riders/users, so operational records remain available for audit and reporting. Admin backups create timestamped database copies.

This first release intentionally does not claim to prevent people from making side arrangements outside the platform. It records all platform requests, assignments, prices, acceptance, completion, ratings, complaints and audit actions, while exposing only the minimum contact information needed for a live job.
