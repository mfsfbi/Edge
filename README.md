# O-System V1

## Deploy on Render
1. Push this repository to GitHub.
2. In Render, choose **New Web Service** or **Blueprint** and connect the repository.
3. The included `render.yaml` sets Python 3.13, installs `requirements.txt`, starts Gunicorn, and attaches `/var/data` for SQLite persistence.
4. Provide `USER_NAME` and `PASSWORD` for the admin workspace. `SECRET_KEY` is generated by Render.
5. The admin workspace is available at `/promise212324`.

The app uses a single Gunicorn worker because the SQLite database is stored on a persistent disk and the dispatch system is designed for a single service instance.
